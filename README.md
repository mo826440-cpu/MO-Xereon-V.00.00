# Xereon

Sistema de gestión para administrar y controlar los procesos productivos de una planta de elaboración.

Repositorio: `MO-Xereon-V.00.00`

## Stack

- Frontend: React (TypeScript) + Tauri
- Backend: Python + FastAPI
- ORM / migraciones: SQLAlchemy + Alembic
- Base de datos: PostgreSQL (`Xereon_Produccion`)
